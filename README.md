# Abhik G. Moulick academic website

This version uses the same **main content sections** as the Google Sites website: Home, About Me, Research, Publications, and News. Contact is included for accessibility.

## Publish on GitHub Pages
1. Create a public GitHub repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` to the repository root.
3. Go to Settings → Pages → Deploy from a branch → main / (root).
4. Visit `https://YOUR-USERNAME.github.io/`.

## Edit
All layout, styling, and mobile menu scripts are embedded in `index.html`; no missing dependencies. Change names, descriptions, dates, and links directly in that file. Google Fonts are optional external dependencies.

## Source and notes
Main content was adapted from publicly available pages at https://sites.google.com/site/abhikghoshmoulick/ (Home, Education / About Me, Publications, News). The Research cards synthesize previously discussed research projects.
Publication status and CV details should be checked before deployment, especially manuscript statuses. No personal photograph or CV was included.
No claim of exact visual duplication of the Google site. The layout follows the modern research-site design previously requested.
