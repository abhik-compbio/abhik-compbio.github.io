# Abhik Ghosh Moulick — Multi-page academic website

This is the **light-theme, multi-page** version of the previous single-page site.

## Pages
- `index.html` — Home
- `about.html` — About Me
- `research.html` — Research
- `publications.html` — Publications
- `news.html` — News
- `contact.html` — Contact
- `style.css` — Shared styling
- `script.js` — Mobile navigation

## Update the existing GitHub Pages site
1. Extract this ZIP.
2. Open your existing `YOUR-USERNAME.github.io` GitHub repository.
3. Choose **Add file → Upload files** and upload **all eight files** to the repository root (not the ZIP and not a folder).
4. If GitHub will not replace `index.html` using the upload interface, open `index.html` → pencil icon, paste the contents of the new `index.html`, and commit. Upload the other seven files normally.
5. Commit changes. Your GitHub Pages settings and website URL stay the same.

All navigation uses relative links, so every section opens as a separate page. Check content, publication status, and external links before publication.
